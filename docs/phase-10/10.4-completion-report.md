## Canonical architecture

The registry is the shared routing layer for all UGC Affiliate OS modules. It does not introduce a second workflow engine or tool policy system. Tool authorization remains governed by the canonical tool-policy layer; Phase 10.4 only filters agents by declared compatibility and available capacity.

## Security

All registration, reservation, release and expiry operations are scoped by `workspaceId`. No cross-workspace candidate can be selected. Unknown capabilities or insufficient capacity fail closed.

## Rollback

The migration adds independent registry and reservation tables. Application rollback can stop using them without modifying existing workflow data. Dropping the tables is destructive and requires a separate reviewed migration.

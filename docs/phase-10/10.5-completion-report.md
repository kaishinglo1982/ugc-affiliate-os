## Security

All reads and writes are scoped by `workspaceId`. The approval check additionally scopes by `resourceType = 'agent_tool_invocation'` and `resourceId = toolId`, so no cross-tenant or cross-tool approval can satisfy a pending requirement. Unknown tools and unset policy context fail closed rather than defaulting to permissive behavior.

## Rollback

The migration only adds an enum value (`ALTER TYPE ... ADD VALUE IF NOT EXISTS`), which Postgres cannot drop transactionally. Application rollback is: stop calling `PostgresToolExecutionGateway`; the unused enum value is inert. Removing the enum value, if ever required, needs a separate reviewed migration that recreates the type.

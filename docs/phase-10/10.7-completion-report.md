# Phase 10.7 — Cost & Budget Controls

**Branch:** `feat/carryos-core-bound-consolidation-20260916`  
**Status:** IMPLEMENTED — CI verification pending

## Delivered

- Reuses existing `BudgetPolicy` and `CostReservation`; no parallel budget core.
- Atomic reservation transaction locks the budget policy row before checking remaining capacity.
- Reserved + consumed reservations count against the configured policy limit.
- Daily, monthly and lifetime policy windows are supported.
- Currency mismatch is fail-closed.
- Non-positive reservation amounts are rejected.
- Durable idempotency key prevents duplicate reservations for the same workspace.
- Consume, release and expiry transitions are explicit and terminal-state-safe.
- Tenant-bound Prisma access is used for all budget operations.

## Security / reliability

- No caller-controlled tenant authority.
- Concurrent reservation attempts serialize on the policy row.
- Replayed idempotency keys return the existing reservation instead of creating a second charge.
- Budget exhaustion fails before a reservation is created.
- Expired reservations can be deterministically moved to `EXPIRED`.
